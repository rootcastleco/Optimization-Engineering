# Scientific English research prompt collection

This collection provides **84 original, fully specified prompts**: **72 chapter-specific workflows** (formulation, experiment and verification for each of 24 textbook chapters), and **12 Rootcastle engineering cases** covering rotor balancing, GNSS, IoT, PCB and numerical release assurance. All 84 prompts are in English, and their input specifications explicitly require evidence rather than fabricated findings.

**Formats:** [structured JSON](optimization_prompts.json) · [tabular CSV](optimization_prompts.csv) · [reading edition](optimization_prompts.md).

**Reference:** Kochenderfer & Wheeler (2026), *Algorithms for Optimization*, 2nd ed. MIT Press. These are original research prompts; neither textbook passages nor textbook figures are republished. See [source and licensing](../docs/source_and_licensing.md).

**Scientific rigor:** real problem statements, explicit assumptions, independent feasibility checks, reproducible test budgets, limitations and PASS/FAIL/NOT VERIFIED evidence gates.
