# Specialized optimization workflows

The fourteen folders below are independent, original Markdown-based ChatGPT-compatible skill *sources*. They are not automatically installed into a user's ChatGPT account.

- [**Optimization Engineering**](rei-optimization-engineering/SKILL.md) — Cross-domain engineering optimization; model formulation, algorithm selection, numerical QA and safety-gated integration. Chapters 1–24.
- [**Optimization Problem Formulation**](rei-optimization-modeling/SKILL.md) — Decision variables, objective functions, scaling and formal feasible-set design. Chapters 1, 10.
- [**Gradient and Hessian Verification**](rei-gradient-verification/SKILL.md) — Analytic, finite-difference, complex-step and automatic differentiation audits. Chapters 2.
- [**Smooth Local Optimization**](rei-smooth-local-optimization/SKILL.md) — Bracketing, line search, gradient descent, quasi-Newton, Newton and Levenberg–Marquardt methods. Chapters 3–6.
- [**Black-Box Optimization**](rei-black-box-optimization/SKILL.md) — Derivative-free, stochastic and population methods for noisy and multimodal objectives. Chapters 7–9.
- [**Constrained and Dual Optimization**](rei-constrained-dual-optimization/SKILL.md) — Constraint transformations, KKT, penalty/barrier approaches, primal–dual updates and ADMM. Chapters 10–11.
- [**Linear, Quadratic and Convex Optimization**](rei-linear-quadratic-convex/SKILL.md) — LP, convex QP, least squares, nonnegative least squares and disciplined convex programming. Chapters 12–14.
- [**Multiobjective and Pareto Optimization**](rei-multiobjective-pareto/SKILL.md) — Pareto dominance, scalarization, epsilon constraints, multiobjective search and preference elicitation. Chapters 15.
- [**Surrogate and Bayesian Optimization**](rei-surrogate-bayesian-optimization/SKILL.md) — Sampling plans, surrogate regression, Gaussian processes, acquisition and safe exploration. Chapters 16–19.
- [**Robust Optimization and Uncertainty Propagation**](rei-robust-uncertainty-optimization/SKILL.md) — Set-based uncertainty, chance constraints, Monte Carlo, Taylor approximations and polynomial chaos. Chapters 20–21.
- [**Discrete Optimization**](rei-discrete-optimization/SKILL.md) — Integer programming, cutting planes, branch and bound, dynamic programming and combinatorial search. Chapters 22.
- [**Expression Evolution**](rei-expression-evolution/SKILL.md) — Typed grammars, genetic programming and symbolic expression search. Chapters 23.
- [**Multidisciplinary Design Optimization**](rei-multidisciplinary-optimization/SKILL.md) — Coupled subsystem design using MDF, IDF, collaborative and simultaneous analysis architectures. Chapters 24.
- [**Optimization Verification and Release Assurance**](rei-optimization-verification/SKILL.md) — Benchmarks, feasibility audits, regression gates, derivative tests and release evidence. Chapters 1–24, Appendix B.

**Installation note:** This repository contains skill source folders. To upload individual skills into an environment that accepts ZIPs, package the appropriate folder with its `SKILL.md` at its archive root and validate its metadata first. See [scientific validation](../docs/validation_protocol.md).
