## Relationship to the code

The record describes the framework as fourteen agent-workflow specifications, eighty-four research prompts, numerical smoke tests, a gradient audit, Rosenbrock experiments under a shared 450-evaluation budget and a GitHub continuous-integration pipeline. These are the *documented* software research components; machine safety interlocks, GNSS field testing and embedded deployment gates are not thereby certified.

**Evidence limitation:** one deterministic test case and a single initialization point cannot prove universal convergence performance, statistical significance or industrial field readiness. Cite the archived publication as research documentation, not as proof of a formally peer-reviewed or certified standard.
